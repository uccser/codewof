# Fizz Buzz To N

Write a program that asks for a positive whole number, then for every number from 1 up to and including that number:

- **print** `FizzBuzz` if the number is divisible by both 3 and 5
- **print** `Fizz` if the number is divisible by 3
- **print** `Buzz` if the number is divisible by 5
- otherwise **print** the number

*Hint: the `%` (modulo) operator is useful for finding out if a number is divisible by another number.*
