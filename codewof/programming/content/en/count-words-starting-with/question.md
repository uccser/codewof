# Count Words Starting With

Write a function `count_starting_with(words, letter)` that takes a Python list of strings, `words`, and a single character string, `letter`, and **returns** how many of the strings start with that letter.

The check should not be case sensitive, so `Kea` starts with `k`.

*Hint: the string methods* `str.lower()` *and* `str.startswith()` *may be helpful.*
