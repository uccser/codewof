# Sum Every Second

Write a function `sum_every_second(numbers)` that takes a Python list of numbers, `numbers`, and **returns** the sum of every second number, starting with the first.

For example, `sum_every_second([1, 2, 3, 4, 5])` should **return** `9` because 1 + 3 + 5 = 9.

*Hint: the `range` function can take a step, e.g. `range(0, 10, 2)`.*
