# Strong Password

Write a program that repeatedly asks the user for a password until they enter one that is at least 8 characters long.

Each time the password is too short it should **print** `Too short!`.
Once a long enough password is entered it should **print** `Password accepted!`

*Hint: a* `while` *loop is a good type of loop to use when you don't know how many times the loop will run.*
