# Koha Boxes

A marae collects koha in boxes that each hold 20 envelopes.

Write a function `boxes_needed(envelopes)` that takes the number of envelopes and **returns** how many boxes are needed so that every envelope fits in a box.

For example, 21 envelopes need 2 boxes.

*Hint: the `%` (modulo) operator and the `//` (floor division) operator may be useful.*
