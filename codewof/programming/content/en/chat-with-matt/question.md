# Chat with Matt

Here is a function that prints a question and asks for the
users name, then depending on what the user types in as their name
the program will then respond saying "Your name starts with an M as well!"
if the entered name starts with M or with "It is nice to meet you {name}!"
if the name does not start with M. Your task is to modify this program
so that if the entered name does not start with 'M' but it ends with 't',
then the program should print "We both have names ending with t!". 
Otherwise, if the entered name does not start with 'm' or end with 't'
then is should print "It is nice to meet you {name}!"
