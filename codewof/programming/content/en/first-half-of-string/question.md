# First Half of String

Write a function `first_half(text)` that takes a string, `text`, and **returns** the first half of the string.

If the string has an odd number of characters, the middle character should not be included.

*Hint: the `//` (floor division) operator rounds down to the closest whole number, and string slicing, e.g.* `text[:3]`*, may be useful.*
