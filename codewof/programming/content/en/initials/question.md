# Initials

Write a program that asks for a person's first name and then their last name, and **prints** out their initials in UPPERCASE with a full stop after each letter.

For example, if the user enters `Aroha` and then `Kepa`, your program should **print** `A.K.`

*Hint: the string method* `str.upper()` *and string indexing may be useful here.*
