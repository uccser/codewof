# Sum Even Indexes

Write a function `sum_even_indexes(numbers)` that takes a Python list of numbers, `numbers`, and **returns** the sum of the numbers at even indexes (index 0, 2, 4 and so on).

For example, `sum_even_indexes([1, 2, 3, 4, 5])` should **return** `9` because 1 + 3 + 5 = 9.

*Hint: the `range` function can take a step, e.g. `range(0, 10, 2)`.*
