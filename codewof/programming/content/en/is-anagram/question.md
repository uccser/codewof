# Is Anagram

Two words are anagrams if they use exactly the same letters, just in a different order.

Write a function `is_anagram(word1, word2)` that takes two strings and **returns** `True` if they are anagrams of each other, or `False` otherwise.

You can assume both words are all lowercase.

*Hint: the built in function* `sorted()` *returns a sorted list of the characters in a string.*
