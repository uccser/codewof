# Rocket Launch Countdown

Write a program that asks for a whole number to count down from.

Your program should **print** every number from the given number down to 1, each on a new line, and then **print** `Liftoff!`

If the given number is less than 1, only `Liftoff!` should be printed.

*Hint: the* `range` *function can take a step, e.g.* `range(10, 0, -1)`*.*
