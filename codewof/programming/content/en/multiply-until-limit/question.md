# Multiply Until Limit

Write a program that asks for a whole number, then repeatedly **prints** the number and doubles it, while the number is 100 or less.

For example, if the input is `10` your program should print `10`, `20`, `40` and `80`.

*Hint: a* `while` *loop is a good type of loop to use when you don't know how many times the loop will run.*
