# Countdown by Twos

Write a function `countdown_by_twos(start)` that uses a while loop to **print** `start`, then `start - 2`, then `start - 4` and so on while the number is still greater than 0.

Once the countdown has finished it should **print** `Done!`

*Hint: a* `while` *loop is a good type of loop to use when you don't know how many times the loop will run.*
