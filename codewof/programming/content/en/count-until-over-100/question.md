# Doubling Past 100

Write a program that asks for a starting whole number, then repeatedly doubles it until it is greater than 100.

Your program should **print** how many times the number had to be doubled.

If the starting number is already greater than 100, your program should **print** `0`.

*Hint: a* `while` *loop is a good type of loop to use when you don't know how many times the loop will run.*
