# Join With Dashes

Write a function `join_with_dashes(words)` that takes a Python list of strings, `words`, and **returns** a single string with all the words joined together by dashes.

For example, `join_with_dashes(['kia', 'ora'])` should **return** `'kia-ora'`.

There should be no dash at the end of the returned string.

*Hint: string slicing, e.g. `text[:-1]`, removes the last character of a string.*
