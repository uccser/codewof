# Secret Kiwi Word

Write a program that repeatedly asks the user for the secret password until they enter `kiwi`.

Each time the user enters the wrong password, your program should **print** `Nope, try again`.
Once the user enters `kiwi`, your program should **print** `You got it!` and stop.

*Hint: this question is case sensitive, so `KIWI` is not the same as `kiwi`.*
