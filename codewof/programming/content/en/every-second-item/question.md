# Every Second Item

Write a function `every_second(items)` that takes a Python list, `items`, and **returns** a new list containing every second item, starting with the first item.

For example, `every_second([1, 2, 3, 4, 5])` should **return** `[1, 3, 5]`.

*Hint: the `range` function can take a step, e.g. `range(0, 10, 2)`.*
